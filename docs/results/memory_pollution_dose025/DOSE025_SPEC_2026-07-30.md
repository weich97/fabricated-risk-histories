# Low-dose follow-up — frozen before dose-0.25 provider calls (2026-07-30)

> Public copy of a specification frozen in the author's development repository.
> Internal project labels were removed; the design, hypotheses and analysis
> text are unchanged.

The three-regime results were already known when this follow-up was proposed.
This is therefore a separate prospective extension, not part of the earlier
12-test regime family. No dose-0.25 provider result had been collected or read
when this document was written.

## Question

The directive-removed bullish experiment currently observes clean memory and a
0.75 fabricated-violation dose. This follow-up asks whether a smaller 0.25 dose
already changes model behavior. It adds one point to the existing two-point
comparison; it is not presented as a complete dose-response curve.

## Frozen grid

- Market: existing `bullish` generator, 24 steps, symbols `SYN,ALT`.
- Models: `deepseek:deepseek-v4-pro` and `glm:glm-5`, direct APIs.
- Prompt: directive removed (`--risk-feedback-mode neutral`).
- Corruption: `fake_violations`, dose 0.25, decay 0.85.
- Risk gate: `none`.
- Seeds: 1--30.
- Provider samples: 0, 1, and 2.
- New collection: `2 models x 30 seeds x 3 samples = 180 runs`, representing
  4,320 logical provider calls.
- Execution: $100,000 initial cash, 1 bp commission, 2 bp base slippage,
  5% participation, one-step latency, and market-impact coefficient 0.15.

The comparison reuses the already released directive-removed bullish dose-zero
rows. Those controls were collected earlier, so every dose-0.25 contrast relies
on provider-service stability across batches. This limitation will be stated in
the paper. Reusing the controls is the design proposed before this addendum; no
new clean arm will be introduced after the dose-0.25 results are read.

## Estimands and analysis

Provider samples are averaged within each seed. Within each model and outcome,
the estimand is dose 0.25 minus dose 0.

Primary outcomes:

1. hold ratio;
2. mean gross approved target exposure.

The four primary tests (2 models x 2 outcomes) form one new
Benjamini--Hochberg family. We will report paired-bootstrap 95% intervals,
paired sign-flip permutation p-values, corrected q-values, and standardized
paired effects.

`total_return` and `max_drawdown` are exploratory and retain uncorrected
p-values. Sharpe ratio will not be reported. For visualization only, the
analysis will also emit the seed-averaged means at doses 0, 0.25, and 0.75 from
the combined existing and new records. No additional hypothesis test will be
created from the curve.

## Interpretation rule

- If the low-dose effects retain the high-dose direction, report their size and
  uncertainty without claiming linearity.
- If they are mixed or interval-crossing, report that the current evidence is
  concentrated at the 0.75 stress dose.
- Regardless of direction, update the paper and the released artifact.
- Do not add doses, seeds, prompt variants, outcomes, or market subgroups after
  reading the first dose-0.25 result.
